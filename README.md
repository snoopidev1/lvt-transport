# LVT Transport

**The digital platform behind a transport company.**

🌐 [lvttransport.dk](https://lvttransport.dk)

A complete set of tools that lets a transport company run its daily operations online — from the customer's booking to the driver's delivery.

## Highlights

- **Customer portal** — booking, tracking and documents for customers.
- **Trucking portal** — planning and dispatch of tours and drivers.
- **Driver app** — the day's tasks, proof of delivery and updates on the road.
- **3D load planning** — see how goods fit on the trailer before loading.
- **Admin and integrations** — mail booking, SMS, users and roles.

## Tech

PHP · JavaScript · MySQL · mail and SMS integrations · 3D visualisation in the browser.
